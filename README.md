# RFM Customer Segmentation

## Overview

This project uses RFM (Recency, Frequency, and Monetary) analysis to understand customer purchasing behavior and segment customers based on their transaction history.

## Objectives

* Analyze customer purchasing patterns using transaction data.
* Calculate Recency, Frequency, and Monetary values.
* Group customers based on their RFM scores or segments.
* Identify customer behavior patterns to support business decision-making.

## RFM Metrics

* **Recency:** How recently a customer made a purchase.
* **Frequency:** How often a customer makes purchases.
* **Monetary:** How much a customer spends.

## Technologies Used

* Python
* Pandas 
* Matplotlib / Seaborn
* Machine Learning

## Project Files

* **Source Code:** RFM analysis code file(s).
* **Project Report:** Report explaining the analysis and findings.

## Key Outcomes

Customer segments are identified based on RFM metrics to help understand purchasing behavior and support customer retention strategies.
